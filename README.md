# pension-fund-manager
Pension Fund Manager

## Apps

- **Pension Fund Manager** — `index.html` (served at `/`)
- **World Cup Draw** — `world-cup-draw.html` (served at `/world-cup-draw.html`)

Both are single-file, dependency-free pages. Once GitHub Pages is enabled
(Settings → Pages → Source: **GitHub Actions**), the site deploys on every
push to `main` and the World Cup draw is available at
`https://hodgy007.github.io/pension-fund-manager/world-cup-draw.html`.
